# ReadyNest Corp - Sales Performance & Predictive Analytics

An interactive, web-based dashboard and exploratory data analysis (EDA) pipeline built for ReadyNest Corp.

## 🌟 Key Features
- **Responsive Dashboard**: Dynamic filtering by Region, Category, and Timeframe using Chart.js & Tailwind CSS.
- **Exploratory Data Analysis**: Real-time statistical metrics calculation (Mean, Median, Std Dev, Pearson Correlation).
- **Predictive Forecasting**: Integrated 3-month sales moving-average projections.
- **Automated Insights**: Dynamic executive takeaway generator based on filtered data parameters.

## 🛠 Tech Stack
- **Frontend / Visualization**: JavaScript (ES6+), Chart.js, Tailwind CSS
- **Data Engineering**: Python, Pandas, NumPy
- **Hosting**: GitHub Pages
